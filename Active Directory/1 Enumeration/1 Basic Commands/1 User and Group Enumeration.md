> View all accounts in the domain:

```
net user /domain
```

> View all local accounts:

```
net user
```

> Check what groups the current user is in:

```
whoami /groups
```

> Query information about an individual user:

```
net user <username> /domain
```

> View all groups in the domain:

```
net group /domain
```

> Query information about a group:

```
net group "<group_name>" /domain
```
