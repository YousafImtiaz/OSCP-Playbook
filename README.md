# OSCP-Playbook

<img src="https://img.shields.io/badge/OSCP-Playbook-orange?style=for-the-badge&logo=linux" alt="OSCP Playbook Badge">

A cheatsheet/playbook I created in Obsidian during my study for the OSCP certification and also what I used during my OSCP exam.

## How to download and import this into Obsidian

1. Download the .md file from the repository.
2. Open Obsidian and navigate to your desired vault/folder.
3. **Copy** the downloaded file into your vault directory.
4. **Refresh** the file explorer in Obsidian (or restart the app) to see the new file.
5. **Open** the playbook and start taking notes alongside it.
