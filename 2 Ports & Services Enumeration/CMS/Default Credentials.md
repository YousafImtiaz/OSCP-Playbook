If you find a CMS login page automatically search for default credentials for that service on google and try a few combinations. If the hosted service is private than you can try some common default credentials such as:

| admin         | admin         |
| ------------- | ------------- |
| admin         | password      |
| root          | root          |
| root          | password      |
| guest         | guest         |
| administrator | administrator |
| administrator | password      |

**IMPORTANT:** If you have a username but no password, try the username as the password. Do this with both login portals and exploits to which require credentials.

If the CMS portal has employee names or emails, they could be potential usernames and/or passwords as well.
